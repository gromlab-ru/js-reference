# Код-стайл TypeScript

## Пробелы и скобки

- Используй 2 пробела на уровень вложенности. Не выравнивай `:` и `=` пробелами в столбец.
- После запятой и двоеточия ставь один пробел, если запись продолжается на той же строке: `load(id, locale)`, `id: string`. Перед ними пробел не ставь.
- Отделяй `=`, `=>`, `|` и `&` пробелами: `limit = 10`, `id => id`, `User | Guest`, `User & Author`.
- В однострочном объекте и именованном импорте оставляй пробелы у фигурных скобок: `{ id, name }`, `import { parse } from './parser'`. Пустой объект пиши как `{}`.
- У краёв круглых, квадратных и угловых скобок пробелы не ставь: `load(id)`, `users[0]`, `Map<string, User>`.
- При вызове пиши `load(id)` без пробела перед `(`. После `if`, `for` и `while` перед `(` ставь пробел.
- Открывающую `{` ставь на строке с объявлением или условием: `function load() {`, `if (isReady) {`. Продолжение блока пиши как `} else {` или `} catch (error) {`.

## Строки и разделители

- Для обычных строк используй одинарные кавычки: `'ready'`. Двойные используй, если так требуется меньше экранирования: `"don't"`.
- Для подстановки значений и многострочного текста используй обратные кавычки: `` `Заказ №${id}` ``.
- Не ставь `;` в конце инструкции. Если новая инструкция может продолжить предыдущее выражение, поставь `;` перед ней: `;[first, second] = [second, first]`.
- В объектах, массивах, кортежах, списках параметров и аргументов не ставь запятую после последнего элемента.

## Переносы

- Ориентир длины строки — 120 символов. Не разрывай строковый литерал или URL только ради этой ширины.
- Короткий вызов, объект без комментариев, массив или кортеж оставляй на одной строке. При переносе пиши по одному аргументу, свойству или элементу на строку. Закрывающую скобку ставь на отдельной строке с тем же отступом, что и начало конструкции.
- Если у поля объекта есть JSDoc, отделяй пару «комментарий + поле» от соседних полей одной пустой строкой.
  Между комментарием и его полем, сразу после `{` и перед `}` пустую строку не ставь.
- В многострочном объединении типов пиши каждый вариант на отдельной строке. Ставь `|` перед каждым вариантом, включая первый.

```ts
type DeliveryEvent =
  | 'shipment.created'
  | 'shipment.accepted_by_carrier'
  | 'shipment.arrived_at_sorting_center'
  | 'shipment.received_by_recipient'
```

## Функции и типы

- Опускай необязательные скобки у единственного параметра стрелочной функции: `user => user.id`. С явным типом параметра пиши `(user: User) => user.id`.
- В объявлении функции тип результата записывай после `:`: `function getUser(id: string): User`. В типе функции ставь `=>`: `(id: string) => User`.
- Знак `?` у необязательного поля или параметра ставь вплотную к имени: `cursor?: string`.
- Для массива с простым типом элемента используй `User[]`, для массива с объединением — `Array<User | Guest>`. Для тех же массивов только для чтения — `readonly User[]` и `ReadonlyArray<User | Guest>`.
- В многострочном объектном типе пиши каждое поле на своей строке без `,` или `;` в конце.

```ts
type Page<T> = {
  items: readonly T[]
  nextCursor?: string
}

type LoadPage<T> = (cursor?: string) => Promise<Page<T>>
```
