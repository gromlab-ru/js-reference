# Как мы пишем TypeScript

1. Для объявления данных и сигнатур открой [правила типов](reference/types.md). Для реализации —
   [правила кода](reference/code.md). Для проверок массива, отсутствия значения или неизвестных данных используй
   раздел [«Предикаты и сужение типов»](reference/code.md#предикаты-и-сужение-типов). Перед написанием своей проверки
   найди подходящую операцию в [каталоге `ts-extras`](reference/code.md#каталог-ts-extras).
2. Если правило не позволяет выполнить конкретное требование задачи, отступи от него только в этом месте.
   При изменении поведения проверь результат на характерном входе: например, на пустом списке или переданном `0`.
3. Подключи [профиль Biome](assets/biome/README.md) для форматирования и линта. Сигнатуры проверяй командой
   проверки типов проекта, а смысл имён и выбор конструкции — при ревью.

Для написания и проверки JSDoc используй скилл `jsdoc-standarts`. Архитектуру приложения определяет проект.
