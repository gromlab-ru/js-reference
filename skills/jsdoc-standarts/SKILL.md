# JSDoc: назначение и правила использования

Пиши для человека, который видит объявление, но ещё не читал реализацию. Начни с назначения: для чего нужны эти
данные или какую задачу решает вызов. Затем объясни то, что нужно знать для использования.

Из типа `number | null` видно, что поле допускает `null`. Объясни смысл: «`null` — верхний предел платы не задан».
Если вызов удаляет заявку из переданной очереди, скажи об этом. Название метода массива, которым её удаляют,
для использования функции знать не нужно.

## Перенос строк

Во всех шаблонах переноси текст JSDoc примерно у 80-й колонки, даже если для кода принят ориентир 120.
Считай ширину от начала строки, включая отступ и `* `.

- Выбирай место переноса по смыслу. Продолжай тот же абзац на следующей строке `* `; пустую строку ` *`
  оставляй только между абзацами.
- В длинном пункте списка ставь продолжение под первым символом текста после `- `. Дефис не повторяй.
- Не разрывай идентификатор, выражение в обратных кавычках или URL. Если целиком они не помещаются,
  строка может быть длиннее ориентира.

## Разработка и ревью

- Для автоматической проверки формы [подключи профиль Biome с плагином](assets/biome/README.md). Там же указаны
  совместимая сборка и границы проверки.

  комментарию, затем сверь его с кодом на конкретном примере.
