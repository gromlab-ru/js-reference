# Домены

Доменный юнит владеет одной предметной возможностью приложения: её языком, контрактом, моделями, операциями,
ожидаемыми исходами, состоянием и доменным UI. Общие критерии юнита и направления зависимостей определяет skill
`unit-architecture`, а фасеты и значения сегментов —
[`архитектурный профиль React SPA`](../../project-profile.md).

## Граница домена

Любой потребитель за пределами доменного юнита работает с предметными данными только через публичный фасет домена.

Домен публикует необходимые предметные операции. Их адаптеры принимают предметные входные данные, обращаются к
внешнему источнику и возвращают предметный результат либо предусмотренную доменную ошибку. Для GET-данных, участвующих
в отображении React, домен дополнительно публикует хук владельца данных.

За пределами домена не вызывай напрямую API-клиент, REST-операцию, SDK, хранилище или другой источник его предметных
данных. Не выноси наружу исходные DTO, технические ошибки источника и преобразование его ответов.

Технические возможности без предметного владельца, например телеметрия, локализация или подключение темы библиотеки
компонентов, используются через соответствующие инфраструктурные юниты. Визуальные правила темы принадлежат `ui`.

Наличие React-компонентов не превращает домен в композицию. Компонент остаётся внутренней реализацией домена, пока
использует его модели, операции, хуки или вспомогательные функции. Композиционный юнит получает готовый публичный
доменный контракт и отвечает за его размещение в продуктовой блочной проекции.

## Поток данных

```text
потребитель
→ публичный доменный хук или операция
→ доменный адаптер
→ API-клиент / SDK / хранилище
→ исходный DTO
→ внутренний mapper
→ доменная модель
→ кеш / состояние / UI
```

Публичная функция адаптера сама является доменной операцией: не добавляй поверх неё обёртку, которая только повторяет
вызов. Хук может использовать адаптер внутри домена и добавлять жизненный цикл или кеш, но не заменяет контракт
операции.

Известная ошибка источника преобразуется в ожидаемую доменную ошибку. Неизвестный сбой преобразуется в
`ApplicationDefect` и передаётся границе приложения.
