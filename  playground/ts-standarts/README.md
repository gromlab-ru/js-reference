# Плейграунды TypeScript

Здесь сравниваем способы написать один фрагмент TypeScript. Откройте файл по теме. Между двумя линиями `===` указано,
что сравниваем. Ниже идут примеры; наведите курсор на имя, чтобы увидеть выведенный тип.

**«Хорошо / Плохо»** показывает текущее предпочтение или ошибку на указанных данных.
**«Вариант А / Вариант Б»** оставляет выбор открытым. Если записи ведут себя по-разному, смотрите результат у вызова.
Например, в `control-flow.ts` подстановка через `||` заменит переданный `0`, а через `??` сохранит его.

**Как дополнять:** найдите файл по теме и добавьте секцию с одним вопросом. Для новой пары возьмите одинаковые
исходные данные. При сравнении оформления меняйте только запись; при сравнении JSDoc — только комментарий.
Если выбор зависит от поведения, покажите вход, на котором видна разница.

**Проверка типов:** из этой папки выполните `npm exec --package=typescript@5.9.3 -- tsc -p .`.
Редактор использует тот же `tsconfig.json`, в том числе для необязательных полей и чтения по индексу.
