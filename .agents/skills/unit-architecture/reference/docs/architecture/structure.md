# Физическая структура

Unit Architecture нормирует владельцев и публичные границы, но оставляет внутреннюю структуру юнита проекту.

## Структурные сущности

```text
Layer
└── [Group*]
    └── Unit
        ├── Facet+
        ├── File*
        ├── Segment*
        └── Unit*
```

## Фасет

Фасет — объявленный непустой файл публичной точки входа юнита. Фасеты находятся в корне юнита либо определяются эквивалентным сопоставлением путей проекта.

## Сегмент

Сегмент группирует внутреннюю реализацию по выбранному проектом направлению. Архитектура не устанавливает:

- обязательный набор сегментов;
- их имена;
- допустимые типы файлов;
- необходимость папок внутренних единиц;
- глубину локальной реализации.

Обе формы допустимы:

```text
query-client/
├── index.ts
├── create-query-client.ts
└── query-client.type.ts
```

```text
unit/
├── index.ts
├── unit-name.tsx
├── styles/
├── types/
├── ui/
├── providers/
├── hooks/
├── libs/
├── utils/
└── stores/
```

Вторая форма показывает словарь сегментов, используемый в примерах документации. Архитектура не определяет различия между `libs`, `utils`, `helpers` или любыми другими выбранными именами. Их смысл и содержимое устанавливает команда приложения.

Сегмент не имеет фасета и не импортируется как самостоятельный владелец.

## Форма UI-юнита в примерах

Для UI-проекций примеры используют минимальную базовую форму:

```text
unit-name/
├── index.ts
├── unit-name.tsx
├── styles/
│   └── unit-name.module.css
└── types/
    └── unit-name.type.ts
```

`index.ts` является фасетом. Папки и файлы в примерах именуются в kebab-case. Это соглашение набора примеров, а не требование Unit Architecture к приложениям.

## Группа

Группа содержит только юниты и другие группы. Она используется для навигации и может находиться в слое либо внутри выбранной проектом области юнита.

```text
compositions/
├── layouts/        # Группа
│   └── main-layout/
├── screens/        # Группа
│   └── catalog-screen/
└── widgets/        # Группа
    └── header/
```

Если папка содержит собственную реализацию или фасет, она не является группой.

## Внутренняя папка

Папка без фасета может колоцировать файлы вокруг component, hook, Provider, service или другого механизма. Она не становится юнитом и не участвует в графе зависимостей.

```text
header/
├── index.ts
└── utils/
    ├── get-navigation-label.ts
    └── get-navigation-label.test.ts
```

`utils` здесь является внутренним сегментом юнита Header, а не вложенным юнитом.

## Как различить папки

| Папка | Ответственность | Фасет | Реализация | Узел графа |
|---|---:|---:|---:|---:|
| Юнит | Да | Да | Да | Да |
| Сегмент | Нет | Нет | Да | Нет |
| Группа | Нет | Нет | Нет | Нет |
| Внутренняя папка | Нет отдельно от владельца | Нет | Да | Нет |

Фасет без ответственности не создаёт корректный юнит, а ответственность без фасета не получает завершённой архитектурной границы.
