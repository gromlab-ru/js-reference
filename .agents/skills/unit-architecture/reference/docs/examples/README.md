# Примеры

Примеры показывают отдельные архитектурные решения. Это не обязательные шаблоны каталогов и не runnable demo.

В примерах используются группы `layouts`, `screens`, `widgets` и сегменты `styles`, `types`, `ui`, `providers`, `hooks`, `libs`, `utils`, `stores`. Архитектура не определяет этот словарь и не устанавливает различия между `libs`, `utils`, `helpers` или другими именами: команда приложения самостоятельно проектирует внутреннюю структуру юнита.

Во всех примерах `index.ts` является маркером фасета и зарезервирован во всём frontend root. В SSR-примере дополнительно объявлены специализированные маркеры. Поэтому каждый показанный `index.ts` однозначно объявляет содержащую его папку юнитом и не используется как локальный реэкспорт.

Папки и файлы примеров именуются в kebab-case. Минимальная форма UI-юнита выглядит так:

```text
unit-name/
├── index.ts
├── unit-name.tsx
├── styles/
│   └── unit-name.module.css
└── types/
    └── unit-name.type.ts
```
